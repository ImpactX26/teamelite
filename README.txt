EduGuide AI — Germany Applicant Journey Prototype

Updated for the Educaro problem statement.

The prototype now includes:
- Germany-only destination
- Study / Vocational Training / Employment pathway selection
- evidence-first qualification rules
- education, experience, language and recognition/comparability checks
- extra courses, internships, projects, certifications, awards and volunteering evidence
- document-source labels: verified / applicant-provided / AI-generated / conflict / missing
- reason-specific recovery actions when qualification is blocked
- interview-readiness signal separate from qualification
- verified resume flow
- Applicant -> Educaro Deutschland GmbH -> company routing
- interview-response monitoring and notification simulation

For the hackathon prototype, live OCR, speech-to-text, recognition databases, email sending and inbox monitoring are represented by deterministic UI simulations. Connect those functions to the intended backend services for production.
